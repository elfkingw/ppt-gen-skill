# 字体选择

pptx 不嵌入字体，客户电脑上没有的字体会被替换，字宽一变，排版就会溢出或错位。所以字体按**客户打开 PPT 的环境**来选，不按生成机器来选。

| 客户环境 | 推荐字体（`theme.font`） | 说明 |
|---|---|---|
| Windows + PowerPoint / WPS（默认） | `微软雅黑` | Windows 自带，绝大多数政企客户适用 |
| macOS + Keynote / PowerPoint | `PingFang SC`（苹方） | macOS 自带；Mac 版 Office 也带微软雅黑 |
| 信创（麒麟、统信 + WPS） | `思源黑体` | 系统一般预装思源黑体或 Noto Sans CJK；不确定时先问 |
| 环境不确定 / 跨平台分发 | `微软雅黑` | 同时导出一份 PDF 一起交付 |

规则：

- 全稿只用一种字体，标题靠字重和字号区分。
- 字体只在 `theme.font` 里设置一次；构建脚本会检查每段文字（包括表格单元格）都带了中文字体，避免中文显示成方框。
- 渲染自检时，`scripts/render.sh` 会检查本机有没有这个字体；没有时预览里的字宽和客户端不同，自检溢出要留余量，或先安装同款字体。
